abertas (T021, T011/T012, T035-T040) — não é escopo de T051 resolver.

como Artifacts — fluxo de negócio (swimlane, 2 raias, sem jargão técnico) e
arquitetura técnica (2 zonas, hooks como nó focal, bypass via service role
em Edge Functions). Perfil de marca salvo em

`#FFD600`/cinza `#6B7280`, extraído de `BRAND` em `pdfLogoHelper.ts`).

**Free vs. Pro do Supabase / VPS self-hosted**: análise arquitetural sem
acesso a dados reais (confirmado: só há anon key disponível, sem
`service_role`/senha/Access Token). Pro recomendado com base em sinais
arquiteturais; VPS tecnicamente viável mas decisão real é de capacidade
operacional (backup/PITR, patching, HA), não de hardware.

**ADR-001 — Cenário C**: self-host do stack oficial do Supabase via Docker
numa VPS documentado como alternativa distinta do Cenário B. Status do ADR
continua Proposta. Commit `6694598`, PR #2 atualizado.

### ⚠️ Aprendizados / gotchas

- Revisar sempre o conteúdo de arquivos não-rastreados antes de um commit em
  lote, mesmo quando o pedido é "todos os arquivos" — `scripts/lib/__pycache__/`
  e `supabase/.branches/` foram parados a tempo (foram para `.gitignore`, não
  commitados).
- `scripts/session-manager.py` **quebrado** — `ModuleNotFoundError:
  lib.session` em todos os subcomandos (`end`/`status`/`security-scan`), bug
  do scaffold inicial. Documentado em
  `docs/bugs/2026-09-08-session-manager-import-quebrado.md`, não corrigido
  (fora do escopo do pedido).
- Nenhum servidor MCP do Lovable ou Supabase está configurado neste
  ambiente (nem projeto, nem global).
