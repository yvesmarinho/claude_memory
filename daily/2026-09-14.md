### ⚠️ Aprendizados / gotchas

- `meta: reset_connection` do Ansible **não suporta `when`** — a condição é ignorada silenciosamente e a task sempre roda. Duas ocorrências encontradas hoje no mesmo repo (`ssh-port-detection.yml`, e o novo `detect-connection.yml` já nasceu sem o `when` por causa disso).
- `wait_for` com `delegate_to: localhost` é só um teste TCP — não precisa de conexão SSH válida, então pode rodar **antes** de qualquer `gather_facts`. É a base de qualquer estratégia de auto-detecção de porta.
- `--limit` do Ansible restringe quais hosts uma *play* roda, mas **não filtra** o conteúdo de `groups['x']` referenciado dentro de um `loop` — um padrão perigoso quando se assume que `--limit HOST` isola completamente a execução.
- `$(if ...)` do GNU Make quebra silenciosamente se o argumento contém uma vírgula literal (interpretada como separador de argumentos da função) — precisa de uma variável auxiliar (`COMMA := ,`) pra escapar.
- Provisionar um host novo neste repo tem uma ordem rígida: `site-first-deploy` (autentica como root/senha do vault) **precisa terminar com sucesso antes** de `ssh-spa-deploy` (assume host já hardened, chave `archaris`) — tentar pular essa ordem produz `Permission denied` que parece bug mas é pré-requisito não satisfeito.
- Grupo criado via `community.general.group_by` herda as **vars estáticas** do grupo alvo se ele já existir com `vars:` no inventário — cuidado ao reusar um nome de grupo estático pra classificação dinâmica se esse grupo tiver vars fixas que você não quer herdar (não foi problema aqui porque a detecção de porta roda *depois* e sobrescreve via `set_fact`, mas é uma armadilha real).
