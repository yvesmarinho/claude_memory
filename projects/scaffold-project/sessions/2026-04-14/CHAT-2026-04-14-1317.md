5. O comando `upgrade` é idempotente e usa `.scaffold-state.yaml` para controlar o que foi aplicado

Então a resposta é: **NÃO, as alterações NÃO serão perdidas** porque:
- O sistema é idempotente (nunca sobrescreve arquivos existentes por padrão)
- Existe um comando `upgrade` que re-aplica o template de forma segura
- Você pode usar `--force` se quiser sobrescrever (mas é opcional e explícito)
</details>

Ótima pergunta! Deixe-me esclarecer como o sistema de templates do SpecKit funciona:

## 🛡️ **SIM, suas customizações estão PROTEGIDAS!**

O sistema foi projetado especificamente para **NÃO sobrescrever** customizações. Aqui está como funciona:

### 📋 Sistema de Proteção (3 Camadas)

#### 1. **Cópia Idempotente** (Padrão)
```python
def _copy_file(src: Path, dst: Path) -> CreatedItem:
    """Copia src → dst com logging. Salta se dst já existe."""
    if dst.exists():
        log.info("⏭️  skipped (já existe): %s", dst)
        return CreatedItem(path=dst, kind="file", status="skipped")
```

**Comportamento**: Se o arquivo já existe no destino, ele é **PULADO** (skipped), não sobrescrito.

#### 2. **Arquivo de Estado** (`.scaffold-state.yaml`)
```yaml
scaffold_version: 1.0.0
created_at: '2026-03-20T18:44:10Z'
updated_at: '2026-03-20T18:45:03Z'
project:
  name: meu-projeto
  domain: programming
```

**Função**: Rastreia o que foi aplicado ao projeto, permitindo atualizações incrementais.

#### 3. **Comando `upgrade`** (Seguro)
```bash
# Re-aplica template sem perder customizações
python scripts/scaffold.py upgrade

# Sobrescreve APENAS se você forçar explicitamente
python scripts/scaffold.py upgrade --force
```

### 🔄 Como Funcionam as Atualizações

**Cenário**: Você customizou `.specify/templates/spec-template.md` no seu projeto e o template upstream foi atualizado.

```
┌─────────────────────────────┐
│ scaffold-project (upstream)│
│ .specify/templates/         │
│   spec-template.md (v2.0)   │  ← Nova versão
└─────────────────────────────┘
                ↓
         scaffold.py upgrade
                ↓
┌─────────────────────────────┐
│ seu-projeto (local)         │
│ .specify/templates/         │
│   spec-template.md (custom) │  ← PRESERVADO! ✅
└─────────────────────────────┘
```

**Resultado**: Seu arquivo customizado é **mantido**, novo template é **ignorado**.

### ✅ Fluxo Recomendado para Atualizações

Se você QUER pegar mudanças do upstream:

```bash
# 1. Ver o que mudou
git diff HEAD:.specify/templates/spec-template.md \
  ../scaffold-project/.specify/templates/spec-template.md

# 2. Aplicar mudanças específicas manualmente (cherry-pick)
# Ou mesclar com suas customizações

# 3. Re-aplicar template (pula arquivos existentes)
python scripts/scaffold.py upgrade
```
