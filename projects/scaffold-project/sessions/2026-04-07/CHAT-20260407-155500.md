### **Passo 2: Configurar Cloudflare** (15 min)

**Leia o guia completo**: `docs/CLOUDFLARE_SETUP.md`

**Resumo rápido**:
1. **Criar API Token** no Cloudflare Dashboard
   - Acesse: https://dash.cloudflare.com/ → Profile → API Tokens
   - Permissão: `Cloudflare Pages - Edit`
   - Copie o token

2. **Adicionar Secrets no GitHub**:
   - `CLOUDFLARE_API_TOKEN` = [token copiado]
   - `CLOUDFLARE_ACCOUNT_ID` = [ID da conta Cloudflare]

3. **Inicializar Cloudflare Pages**:
   ```bash
   cd /home/yves_marinho/DevOps/Projetos/yves-eti-br
   python -m venv .venv && source .venv/bin/activate
   pip install -r scripts/requirements.txt

   export CLOUDFLARE_API_TOKEN='<REDACTED>'
   export CLOUDFLARE_ACCOUNT_ID='seu-account-id'
   python scripts/cloudflare_setup.py init
   ```

4. **Configurar DNS**:
   - Cloudflare Dashboard → DNS → Add record
   - Type: `CNAME`
   - Name: `@` (ou `yves.eti.br`)
   - Target: `yves-eti-br.pages.dev`
   - Proxy: ✅ Proxied (laranja)

## 🎯 **Decisões Arquiteturais**

### 1. **Next.js Static Export vs SSR**

**Decisão**: Static export (`output: "export"`)

**Motivo**:
- ✅ Cloudflare Pages otimizado para static
- ✅ Performance máxima (CDN)
- ✅ Custo zero
- ✅ Simplicidade (sem server)
- ✅ Portfolio não precisa de SSR

### 2. **Python Scripts vs Node.js**

**Decisão**: Python para automação Cloudflare

**Motivo**:
- ✅ Biblioteca `requests` mais simples que `axios`
- ✅ Usuário familiar com Python
- ✅ Scripts utilitários separados do frontend
- ✅ Perfil `devops-programming` já inclui Python

### 3. **Monorepo vs Projetos Separados**

**Decisão**: Projeto híbrido (Next.js + Python scripts)

**Motivo**:
- ✅ Python usado apenas para setup inicial
- ✅ CI/CD usa apenas Node.js
- ✅ Simplicidade de manutenção
- ✅ Um único repositório

### 4. **Cloudflare Pages vs Vercel/Netlify**

**Decisão**: Cloudflare Pages

**Motivo**:
- ✅ Domínio já no Cloudflare
- ✅ DNS integrado
- ✅ CDN global superior
- ✅ SSL automático
- ✅ Free tier generoso
